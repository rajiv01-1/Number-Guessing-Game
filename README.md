# Number Guessing Game 🎮

A simple Python-based Number Guessing Game.

## Features

* Random number generation
* User input
* Too High / Too Low hints
* Maximum 7 attempts
* Attempt counter
* New round option

## Technologies

* Python
* Random module
* Loops
* Conditions
* Functions

## How to Run

```bash
python number_guessing_game.py
```
